# Sunset Prior Art

This folder preserves a small curated set of current-preset sunset examples.
These frames prove the sky/cloud path can already make dramatic sunsets. The
known problem is that the island is often not lit/readable enough.

Files:

- `originals/`: full-size selected PNGs copied from the Desktop capture.
- `annotated/`: smaller labeled versions for quick browsing.
- `sheets/sunset-prior-art-contact.png`: labeled contact sheet.
- `metrics.csv` / `metrics.json`: capture metadata and sunset-score data.
